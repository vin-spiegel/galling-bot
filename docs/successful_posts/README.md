# 성공 사례 글 (Few-shot 참고용)

이 폴더에 반응 좋았던 글을 마크다운 파일로 저장하면, 봇이 글을 쓸 때 시스템 프롬프트에 랜덤하게 N개를 주입해서 참고합니다.

## 파일 형식

파일명은 자유 (예: `2026-04-27-신발색.md`).

```markdown
---
gal: yjrs
---
# 제목 한 줄

본문 텍스트.
여러 줄 가능.
```

- `gal: 갤러리ID` — 해당 갤에서만 주입 (생략하면 모든 갤에 공통)
- 첫 번째 `# `로 시작하는 줄이 제목
- 그 아래 전체가 본문
- 인코딩은 UTF-8

## 동작

- 봇 시작 시 이 폴더의 `*.md` 파일 전부 로드
- 매번 글 쓸 때 `board_id`에 맞는 사례만 필터 후 랜덤 N개 추출
- 시스템 프롬프트에 "# 참고할 성공 사례" 섹션으로 주입
- 폴더가 비어있거나 매칭되는 사례가 없으면 섹션 자체가 빠짐 (안전)

## 환경 변수

- `BOT_FEWSHOT_DIR` — 폴더 경로 (기본 `docs/successful_posts`)
- `BOT_FEWSHOT_SAMPLE_SIZE` — 매번 주입할 개수 (기본 `3`, `0`이면 비활성화)
